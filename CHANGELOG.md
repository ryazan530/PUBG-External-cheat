# Changelog

All notable changes to TSLGame External will be documented in this file.

## [4.2.1] — 2025-09-25

### Added
- Aimbot: bone select, FOV, smooth, hardlock, predict
- Player ESP: box, skeleton, head, health, names, distance
- Item ESP: weapons, loot, air drops, attachments
- Radar: scale, lines, transparency
- Misc: no recoil, no sway, HWID spoofer
- External loader (`loader.exe`) with menu (INSERT)

### Improved
- Release pipeline via GitHub Actions (tag `v*` → auto Release)
- README, LICENSE, topics for search visibility

## [4.2.0] — 2025-08-01

### Added
- Initial public external menu build
- Discord support link
